# History of NLP

NLP has a deep history, from early explorations of modeling text to using neural networks to understand context. This course focuses on the neural network phase of NLP. 

## Early Explorations 1940-1969

in 1954, Georgetown-IBM developed a machine which could translate Russian text into english using machine translation. It was relatively simple, essentially using keywords and if else statements. 

## Rule-based systems 1970-1992

Used more sophisticated logic, such as grammar based rules to restructure the format of language.

## Statistical Models 1993-2012

Classified natural language using simple statistical models, such as using linear regression or counting words and symbol frequencies in language. 

## Neural Networks 2013-present

Gather a learned representation to understand context of word choices. For example going to the bank is different than the river bank, neural networks could learn these representations.

Then, attention mechanisms in 2017 demonstrated a way to gain global context between learned embeddings for NLP.

In 2020, researchers at OpenAI discovered that LLM's are few shot learners, meaning the model see examples of the task, instead of updating gradients. (175b parameter model)

In 2022, we learned how to communicate LLMs with humans so well by using reinforcement learning from human feedback to hyperoptimize the model for what humans enjoy (reward modle). (Ouyang et all 2022)
